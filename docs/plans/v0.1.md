# Plan v0.1 : le socle

**But** : Ambroise peut installer Fonte sur son téléphone, se connecter avec un code reçu par e-mail, répondre à 3 écrans d'onboarding et se peser en 2 taps. Tout le reste de l'app repose sur ce socle : sécurité, schéma, design system, CI.

## Étapes (un commit ou plus par étape)

1. **Documentation de base** : `CLAUDE.md`, `SPEC.md`, `README.md`, `CHANGELOG.md`, `docs/`, `audit/`.
2. **Projet Next.js** : Next 16, TypeScript strict, Tailwind v4, oxlint, Vitest, scripts npm.
3. **Design system Fonte** : tokens sombre/clair dans `app/globals.css`, polices Archivo + Public Sans, composants de base (bouton, champ, carte, en-tête avec flèche retour), navigation mobile (onglets en bas + bouton +) et ordinateur (sidebar).
4. **Moteur** : `lib/engine` avec moyenne mobile du poids, rythme hebdomadaire, Mifflin-St Jeor, TDEE, 1RM Epley, conversions d'unités. Tests unitaires.
5. **Schéma v0.1 + RLS** : `profiles`, `user_roles`, `invitations`, `user_modules`, `goals`, `body_weights`, fonctions `is_admin()`, `redeem` via déclencheur sur `auth.users`. Tests RLS sur Postgres local (A ne voit rien de B, aucune table sans RLS, inscription refusée sans code). Migration appliquée au projet Supabase `sport`, types TypeScript générés.
6. **Connexion** : pages Connexion et Inscription (code d'invitation + e-mail), envoi d'un e-mail avec code à 6 chiffres et lien magique, vérification, déconnexion. `proxy.ts` rafraîchit la session et pose la CSP avec nonce.
7. **Onboarding** : 3 écrans (profil ; objectif principal, niveau et date de compétition ; unités et séances par semaine). Les modules par défaut sont activés selon l'objectif.
8. **Accueil + pesée rapide** : carte « Poids » préremplie avec la dernière pesée, boutons −0,1 / +0,1, enregistrement en un tap, moyenne 7 jours et rythme hebdomadaire. Autres onglets en états vides soignés.
9. **Admin minimal** : générer un code d'invitation, voir le nombre d'utilisateurs et de codes utilisés.
10. **PWA** : manifest, icônes dérivées du logo, service worker avec page hors ligne.
11. **CI** : GitHub Actions (lint, types, tests moteur + RLS avec un service Postgres, build, gitleaks), Dependabot.
12. **Vérification** : captures Playwright 375 px et 1440 px de chaque écran, `get_advisors`, revue, PR.
